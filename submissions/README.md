# Submissions

Final CSVs for the auto-scored tasks go here, named exactly as in the pack's `tasks/templates/`:

| File | Task |
|---|---|
| `A1_issues_submission.csv` | A1 data-quality issues (2025) |
| `A2_inventory_2025_submission.csv` | A2 2025 inventory |
| `C1_yields_2027_2031_submission.csv` | C1 yields 2027–2031 |
| `C2_climate_yield_risk_submission.csv` | C2 yield risk 2041–2060 |
| `D1_catchment_priority_submission.csv` | D1 catchment priority |
| `E_answers_submission.csv` | E copilot answers |

**Rules:**
- Every file here must be reproducible from the raw pack with a command listed in the root README.
- Changes to files in this folder need human approval (label `needs-human`).
